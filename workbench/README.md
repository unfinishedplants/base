# GITV local workbench

This tree contains production material that has not crossed a publication or adoption gate. Git ignores everything here except this boundary document.

Local layout:

- `koneta-stock/` — draft observation cards
- `raw-logs/` — source logs and recovered drafts
- `candidates/article-images/` — unadopted article-image Candidates
- `candidates/social-images/` — unadopted promotional Candidates
- `tools/mining/` — local transcript-mining tool that writes only to this workbench
- `legacy/teamwork-pipeline/` — retired pre-workbench tools, including the former automatic deploy path

Nothing in this tree is proof of publication, Canon adoption, or approval. Move a selected artifact into a tracked public directory only after the applicable Human Gate.
